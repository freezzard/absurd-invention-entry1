Entry for the make.fun bounty **One-Sentence Absurd Invention Pitch**. `main.py` runs a local tournament over ten original one-sentence pitches, scoring each on the judge brief — absurdity of the invention, neatness of the pitch, economy of words, freshness of the idea — and writes the winning pitch (114 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning pitch: a laundry hamper that eats any sock whose partner goes missing, so odd socks never pile up again.

## Run it

```sh
python3 main.py
```
